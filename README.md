# 📊 Dashboard Interativo de Performance Logística & SLA

Painel de controle operacional desenvolvido em HTML, CSS e JavaScript (com Chart.js) para monitoramento em tempo real de KPIs logísticos, SLA de entregas, gestão de backlog e identificação de pedidos críticos.

## 🛠️ Tecnologias Utilizadas
* **HTML5 & CSS3** (Interface gráfica responsiva em modo escuro)
* **JavaScript (ES6+)** (Manipulação dinâmica de dados)
* **Chart.js** (Visualização gráfica de KPIs e séries temporais)
* **Git & GitHub** (Versionamento e documentação)

## 📈 Indicadores e Métricas Monitoradas (KPIs)
* **OTIF (On-Time In-Full):** Percentual de entregas realizadas dentro do prazo e sem avarias/faltas.
* **Backlog Operacional:** Total de pedidos retidos no armazém por tipo de bloqueio (ERP/WMS).
* **Lead Time do CD:** Tempo médio de processamento e separação no Centro de Distribuição.
* **Matriz de Pedidos Críticos:** Alerta preventivo para a equipe de gestão de carteira evitar estouro de SLA.

## 💡 Como Visualizar o Projeto
1. Faça o clone do repositório ou baixe os arquivos.
2. Abra o arquivo index.html diretamente em qualquer navegador web.
